About WLP

The Secret Wordlist Garden

WLP is a personal vocabulary environment built to keep words connected to meaning, memory, context, practice, and real use — without giving up ownership of the underlying data.

“More words. A wider world.”

More than a list

A word can carry a definition, examples, connections, pronunciation support, learning hooks, situations, alternatives, review state, and practice history. WLP keeps those layers distinct so each can do its own job.

Local first

Drafts, Local Edits, Learning Metadata, progress, and practice data live in the browser unless you explicitly export or transfer them. The canonical Master remains separate from browser-local work.

Study from many angles

Deck study, Review, Standard Practice, AI Practice, pronunciation tools, and future contextual experiences all work from the same vocabulary foundation rather than becoming separate word lists.

Built to evolve

WLP treats vocabulary learning as an ongoing system: discover a word, enrich it, meet it in situations, practice it, notice what still needs attention, and return with better context next time.

The data layers

Master
The canonical vocabulary deck. Local tools can display changes without silently rewriting the source Master.
Draft
A browser-local new card that can be incomplete, edited, studied, exported, and later promoted through the normal authoring workflow.
Local Edit
A browser-local change to an existing Master card. It can be reviewed and reverted without changing the canonical Master TSV.
Learning Metadata
Entry Type, Sense Hook, Memory Hook, Situation Anchors, Communicative Needs, and Alternative Expressions — kept separate from the card’s canonical definition fields.
Study state
Studied, Review attention, attempts, practice events, and related learning history. These are learning records, not authoring data.

A working principle

WLP does not treat “I recognized it once” as the same thing as mastery. The aim is to build enough connections — meaning, usage, situation, retrieval, and output — that a word becomes easier to notice and use when real life calls for it.

A personal wordlist can become a learning environment when the connections around each word are allowed to grow.
